# FirstOrder.Language.Substructure.closure_le

The entry for model theory, the domain of William's agda-algebras,
translated by issue M1-9 ([#9]).  Mathlib declares
`FirstOrder.Language.Substructure.closure_le` in
`Mathlib.ModelTheory.Substructures`: a substructure contains the
substructure generated by a set exactly when it contains the set.  One
Agda file, `agda/SubstructureClosureLe.agda`, checks under profile CC
(`--safe --cubical-compatible`), with no module parameters.

## Statement

Lean's statement, as `#check` prints it:

    @FirstOrder.Language.Substructure.closure_le : ∀ {L : FirstOrder.Language} {M : Type u_3} [inst : L.Structure M]
      {S : L.Substructure M} {s : Set M}, (FirstOrder.Language.Substructure.closure L).toFun s ≤ S ↔ s ⊆ ↑S

The Agda statement, inside a module that takes `L : Language u v`,
`M : Set w` and an instance argument `⦃ 𝑴 : Structure L ρ M ⦄`:

    closure-le : {p : Level} {S : Substructure (u ⊔ w ⊔ p)} {s : Pred M (u ⊔ w ⊔ p)}
               → toFun (closure p) s ≤ S ⇔ s ⊆ carrier S

They match up to notation, and up to the following:

+  Lean's `Set M`, `M → Prop`, is agda-stdlib's `Pred M p`, a predicate
   with values in `Set p`; Lean's `↔` is agda-stdlib's `_⇔_`, and `↑S`
   is the projection `carrier S`.
+  Lean's `closure L` is the infimum of the substructures containing
   `s`; the `closure` of the Agda statement is the substructure generated
   inductively, agda-algebras's `Sg`.  The file defines the infimum too,
   proves `closure_le` for it (`closureᵢ-le`), and proves that the two
   closures have the same elements (`sg⊆inf`, `inf⊆sg`).
+  `S` and `s` live at the level `u ⊔ w ⊔ p`, which contains the level
   `u` of the function symbols and `w` of `M`; Lean's live in `Prop` and
   `Type u_3`.  Under Impredicativity and levels below says why.
+  Lean's `LowerAdjoint` is generic over two preorders and a map; the
   Agda record fixes the map to `carrier` and the orders to inclusion.

## Tier

`#print axioms` prints `[propext, Classical.choice, Quot.sound]`, so the
entry is T2.  The proof cites two lemmas, as follows:

+  `LowerAdjoint.closure_le_closed_iff_le`, which is T1
   (`[propext, Quot.sound]`);
+  `Substructure.closed S : ↑S ∈ (closure L).closed`, which says that
   `↑(closure ↑S) = ↑S`, an equation between sets.  Mathlib proves it by
   antisymmetry, so by set extensionality, which brings `propext` and
   `funext` (and with `funext`, `Quot.sound`).

`Classical.choice` comes with the constant `closure`, which the
statement mentions, along three routes, each through a proof.  A
breadth-first search of the dependency graph (the probe of
[`../real-sqrt-nonneg/notes.md`][sqrt-notes], Remarks) found them one
at a time, cutting each before searching again, until no path to
`Classical.choice` was left; the three are as follows:

+  `closure` is `sInf {S | s ⊆ S}`, and the proof that the infimum is
   closed under the function symbols, `instInfSet._proof_1`, splits on
   `t ∈ s` with `by_cases`, which takes its `Decidable` instance from
   `Classical.propDecidable`.  The data of the infimum, its carrier
   `⋂ t ∈ s, ↑t`, is constructive; the case split is in a proof.  It is
   a second instance of LF-10, which part 1 of [#9] proposes on [#75]:
   `by_cases` on a proposition with no `Decidable` instance in scope
   makes a proof classical without saying so.
+  The type of `closure`, `LowerAdjoint ((↑) : L.Substructure M → Set M)`,
   needs a preorder on `Set M`, and the instance found is the one that
   comes from `Set.instCompleteAtomicBooleanAlgebra`, whose proofs reach
   `Prop.instBooleanAlgebra`, where the law `⊤ ≤ p ⊔ pᶜ` for propositions
   is excluded middle (`Classical.em`).  The order itself is inclusion.
+  `closure._proof_1`, the proof of the Galois connection that `closure`
   carries, uses `sInf_le` from `Substructure.instCompleteLattice`, whose
   proof goes through `isGLB_biInf`, `Subtype.range_coe` and
   `Set.image_univ`, and `Set.image_univ`'s proof uses
   `Classical.byContradiction`.

A second test agrees: a walk of the dependency graph from `closure` that
never enters a constant whose type is a proposition (a theorem or a
proof's auxiliary definition) visits 333 constants and does not reach
`Classical.choice`.  So the closure is classical only in proofs.

The export's axiom declarations are the same three (Lean issue
[lean4#15226] does not affect the set).

The statement survives de-classicalization, with nothing to abstract:
the Agda file proves it with no module parameter and no postulate, for
both closures, so in Agda the entry is T0.  A constructive proof is
known: it is the universal property, in agda-algebras as `sgIsSmallest`.
Both classical steps in Lean are inessential: one is a case split that
the proof of closure under the function symbols does not need (the Agda
`sInf` proves it in one line), the other an instance search that reaches
the order on sets through a Boolean algebra.

### Impredicativity and levels

Lean's `Substructure` has a carrier `Set M`, so `L.Substructure M`
lives in `Type w`, the universe of `M`.  The infimum of a set `T` of
substructures has the carrier `⋂ t ∈ T, ↑t`, whose membership,
`∀ t, t ∈ T → x ∈ t`, quantifies over substructures; `Prop` absorbs the
quantification, so the infimum is a `Set M` again and a substructure of
the same type.  That is what lets Mathlib define the closure as an
infimum and package it as a `LowerAdjoint` of the carrier map, a map from
`Set M` back to the same `L.Substructure M`.

Predicatively, with `Set M` read as `Pred M p`, a substructure lives in
`Set (u ⊔ w ⊔ suc p)`, and the membership of an infimum over
substructures of level `p` lives at level `u ⊔ w ⊔ suc p`.  The file's
`sInf` has exactly that type, and `closureᵢ s` for `s : Pred M p` is a
substructure of level `u ⊔ w ⊔ suc p`.  For Lean's `closure` to be a
lower adjoint, the infimum would have to land at the level it ranges
over, which asks `suc p ≤ p`.  So the definitions `instInfSet` and
`closure` have no predicative assignment of levels: they use
impredicativity essentially, and a translator that follows Lean's
definitions, specializing and solving level constraints as the gap
catalog plans ([#28], [#29]), will report them, and `closure_le` with
them.  That settles the expectation the corpus README records as open
(Coverage) for this entry, and for the definitions only.

The theorem does not need them.  `closure_le` survives in two predicative
forms, both in the file, as follows:

+  **The infimum one universe up**.  `closureᵢ-le` states
   `closureᵢ s ≤ S ⇔ s ⊆ carrier S` for `S` of level `p`, the level the
   infimum ranges over, with an order `_≤_` between substructures of two
   levels.  The proof is the universal property in each direction, one
   line each.  It is not Lean's typing: the closure and `S` have
   different types.
+  **The inductive closure**.  agda-algebras generates a subuniverse with
   `Sg`, whose constructors quantify over function symbols and tuples of
   elements but never over subsets, so `Sg s : Pred M (u ⊔ w ⊔ p)` for
   `s : Pred M p`, with no `suc`.  At any level `𝓁` that contains `u ⊔ w`
   (written `u ⊔ w ⊔ p`), `Sg` maps `Pred M 𝓁` into `Pred M 𝓁`, so it is
   a lower adjoint of the carrier map there, as Lean's closure is, and
   `closure-le` is its Galois connection.  `sg-smallest`, agda-algebras's
   `sgIsSmallest`, holds for substructures of every level.

The infimum cannot take part 1's shape for the lattice of
`order-hom-map-lfp`, a complete lattice whose infimum takes the subsets
of the carrier at the level of its order ([#75]).  That lattice is a
record parameter, so the existence of its infima is assumed; here the
infimum of substructures is constructed, and the construction quantifies
over substructures, which lands it a universe up.  A predicative
complete lattice of substructures takes infima of families indexed by a
small type instead, as agda-algebras does.

The bookkeeping is the same as agda-algebras's for its lattice of
subuniverses (`src/Setoid/Subalgebras/CompleteLattice.lagda.md`), which
it evaluates at "the absorbing level `L = 𝓞 ⊔ 𝓥 ⊔ α ⊔ ℓ₀`", with
intersections and joins of families indexed by `ℓ₀`-small types.  The
level `v` of the relation symbols, and `ρ` of the relations, never
enter: substructures are closed under functions only.  The two closures
have the same elements wherever both are defined: `sg⊆inf` for `s` of
any level, and `inf⊆sg` for `s` at the absorbing level, where `Sg s` is
among the substructures the infimum ranges over.

Lean's proof route does not carry over.  Mathlib proves `closure_le`
through `closed S : ↑(closure ↑S) = ↑S`, an equation between sets, and
the closure operator's lemma; the equation is where `propext` and
`Quot.sound` enter.  For the infimum the equation does not typecheck
predicatively (its sides live at different levels), and for `Sg` it is
an equation between a proof-relevant predicate and `S`'s carrier, which
holds only as a logical equivalence.  Both Agda proofs use the Galois
connection directly.  In Lean, too, `closure_le` is the field `gc'` of
`closure` at `s` and `S`: a scratch theorem stated as `closure_le` with
the proof `(Substructure.closure L).gc' s S` was accepted at the pin.
Its axioms are the same three, since `closure` already carries them, so
the detour through `closed` changes the proof but not the tier.

## Instance arguments

The statement carries 27 instance arguments.  It binds one instance,
`[inst : L.Structure M]`, which it passes to every occurrence of
`Substructure`, `closure` and the `SetLike` and order instances on
substructures; the rest are the instance chains for the order on
substructures (`Substructure.instPartialOrder`, `PartialOrder.toPreorder`,
`Preorder.toLE`) and for the preorder on `Set M` in `LowerAdjoint`'s type
(`Set.instCompleteAtomicBooleanAlgebra`, then
`CompleteAtomicBooleanAlgebra.toCompleteBooleanAlgebra`,
`CompleteBooleanAlgebra.toCompleteLattice`,
`ChainCompletePartialOrder.instOfCompleteLattice` and
`ChainCompletePartialOrder.toPartialOrder`), with `Set.instLE` for `⊆`
and `Substructure.instSetLike` for the coercion.  The proof carries 19,
the same chains for `closure_le_closed_iff_le`, and the closure 44,193.
The count is of arguments at instance-implicit positions of applications
with a constant head.

In Agda one instance argument remains: `L.Structure M` becomes the
record `Structure L ρ M`, which the module takes as
`⦃ 𝑴 : Structure L ρ M ⦄`, so every definition in it takes the structure
by instance search, as Lean's do.  The order instances become two
definitions, inclusion of carriers and agda-stdlib's `_⊆_`; `SetLike`
becomes the projection `carrier`; and the lattice instances disappear,
since the infimum is defined directly.

## The Agda version

One file, `agda/SubstructureClosureLe.agda`, profile CC, no parameters,
in six sections, as follows:

+  `Language`, `Structure` (relations at a level `ρ`), `ClosedUnder`,
   `Substructure` and the order, transcribed from Mathlib.
+  Mathlib's closure: `sInf` of a predicate on substructures and
   `closureᵢ s = sInf (λ S → s ⊆ carrier S)`, with `closureᵢ-le`.
+  agda-algebras's closure: `Sg` with the arity `Fin n` and the arguments
   `Fin n → M` of a first-order language, `closureₛ`, `sg-smallest` and
   `closureₛ-le`.
+  `LowerAdjoint` at a level `𝓁`, `closure p : LowerAdjoint (u ⊔ w ⊔ p)`
   from `Sg`, and the theorem `closure-le` in Lean's shape.
+  The agreement of the two closures.
+  Languages as agda-algebras's signatures, below under Remarks.

`Set M` is `Pred M p`, not the `Ω`-valued `ℙ` of the entries `set-ext`
and `subgroup-card-dvd`, because `closure_le` never asks membership to
be a proposition, and asking would cost parameters Lean does not need:
the infimum's membership is a proposition only with `funext` (a product
of propositions is a proposition by function extensionality), and `Sg`'s
is not one at all, since an element of `Sg s` carries its derivation, so
it would need the propositional truncation of `subgroup-card-dvd`.
Under encoding A of [#27], generated substructures are where Lean's
`Prop` saves the most.

## Remarks

**Mathlib's first-order structures and agda-algebras**.  The issue asks
how the two relate; agda-algebras was read at
`~/git/ualib/agda-algebras/master` (commit `f067d57d`), and not
imported, since the corpus is checked with agda-stdlib and cubical only.

+  **Signatures**.  A Mathlib `Language` is two families indexed by
   arity, `Functions n` and `Relations n`.  An agda-algebras signature
   (`Overture.Signatures`, and the record `signature` of
   `Legacy.Base.Structures.Basic`) is a type of symbols with an arity
   type for each.  A language gives two signatures, with symbols
   `Σ ℕ Functions` and `Σ ℕ Relations` and arity `Fin n`; the file
   defines them (`functions`, `relations`).  The converse fails:
   agda-algebras allows any type as an arity, infinitary operations
   included, and Mathlib only `Fin n`.
+  **Structures**.  Mathlib's `L.Structure M` is a class over a bare type
   with Lean's equality: `funMap`, and a `Prop`-valued `RelMap`.  Its
   closest counterpart is agda-algebras's `Legacy` record `structure 𝐹 𝑅`:
   a carrier, an operation for each symbol of `𝐹` and a relation, valued
   in `Type ρ`, for each symbol of `𝑅`.  Two differences: agda-algebras
   bundles the carrier into the record where Mathlib's class is
   unbundled, and agda-algebras's main line (`Setoid.Algebras`) puts a
   setoid on the carrier, with operations that respect it, and has no
   relation symbols; the setoid is how agda-algebras avoids function
   extensionality and quotients, which Lean has.  A Mathlib structure is
   a setoid algebra for the setoid of Lean's equality.
+  **Substructures**.  Mathlib's `Substructure` (a carrier with
   `fun_mem`) is agda-algebras's `Subuniverse` (`sset` with `isSub`), and
   its `ClosedUnder f` for every `f` is agda-algebras's `Subuniverses`
   predicate; the file proves the correspondence symbol by symbol
   (`substructure→subuniverse`, `subuniverse→substructure`).
   agda-algebras's `Legacy` `Substructure 𝑨` is another notion, a
   structure with an injective homomorphism into `𝑨`; Mathlib's
   counterpart is the structure it induces on a substructure
   (`Substructure.inducedStructure`) with its embedding.
+  **Generation**.  Mathlib's `closure` (an infimum) is agda-algebras's
   `Sg` (inductive); `closure_le` is `sgIsSmallest` with `var`;
   `ClosedUnder.sInf` and `instInfSet` are `⋂s`, which agda-algebras
   indexes by a type `I : Type ι`; Mathlib's
   `coe_closure_eq_range_term_realize` (the closure is the set of values
   of terms over `s`) is agda-algebras's `TermImage`, with
   `SgB-onlyif-TermImageB` and `TermImageB-onlyif-SgB`; and Mathlib's
   complete lattice of substructures is agda-algebras's
   `Setoid.Subalgebras.CompleteLattice`, at the absorbing level.

So the two libraries share their definitions up to bundling, setoids and
arity types, and differ where Lean's impredicative `Prop` lets Mathlib
take infima over all substructures and agda-algebras takes them over
small families or generates inductively.  A translated Mathlib model
theory could meet agda-algebras through the maps of the file's last
section: a language's function signature, and a structure's operations
as an algebra over it.
